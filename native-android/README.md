# Clash IQ Native (Android)

A separate native Android experiment. The existing Capacitor Beta is not modified or replaced.

- Kotlin + Jetpack Compose
- Separate package: `com.clashiq.nativeapp`
- Intended to reuse the existing Clash IQ backend and APIs after their contracts are verified.
- Keep all native source and configuration under `native-android/`.

The Beta remains the working reference and safety net.
