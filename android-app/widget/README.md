# Clash IQ Android Home-Screen Widget

Native Android widget for the prerelease shell.

## V1

Shows:
- BHABE DHEMONS
- current war state
- stars
- destruction
- attacks remaining
- time remaining

Tap opens Clash IQ War Center.

The widget reads the public Clash IQ dashboard endpoint:
https://clash-iq2-testing.onrender.com/api/clash/dashboard?clanTag=%232Q0Q82C9R

The native files are intentionally isolated under this directory until the Android release project is ready to absorb them. This branch must not change Clash 2.0 main or deploy the web app.
